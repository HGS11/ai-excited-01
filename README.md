# Breakthrough

Breakthrough is a bold comic-poster image of a white-hot core punching through a cracked ink-navy wall. Run it with Node 22 using node main.ts; it writes entry.png to MAKEFUN_OUTPUT_DIR or /output.

The white core against the near-black field delivers the jolt at a glance. The wall shards and lower-left WOW badge add the surprise. Radiating speed lines, outward shards, and the rising diagonal create momentum. Hand-drawn flat shapes, antialiased edges, and bitmap letters provide craft. The large core and badge preserve the image's read at small sizes.
